## Group presentation

### Group formation

- A maximum of three members is permitted in each group.
- Every group member must present part of the overall presentation.
- The full group presentation must be no more than 15 minutes.
- Each member may present for a maximum of six minutes.

### Aim

Develop and compare AI-based models using general machine learning and deep learning. The required general machine-learning models are:

- Decision Tree
- Random Forest
- Naive Bayes

The required deep-learning model is a multilayer artificial neural network (ANN/MLP). Additional models may be included if they make the study more comprehensive, for example an LSTM or RNN.

Compare the models using several evaluation measures, including:

- Accuracy
- Precision
- Recall
- F1-score
- Other appropriate measures, such as ROC-AUC and a confusion matrix

### Development platform

Use Python with Jupyter Notebook or another suitable IDE.

### Dataset

Use a relevant dataset from one of these sources:

- [Kaggle datasets](https://www.kaggle.com/datasets)
- [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets.php)

If another data source is required, email the Unit Coordinator for approval before using it.

## Suggested presentation content

The presentation may include, but is not limited to:

- Group information and project title
- Introduction and motivation
- Dataset description
- Dataset analysis
- Feature selection
- Transformation, preprocessing, and feature engineering
- Algorithm and model overview, including testing
- Model-performance evaluation on the test data
- Conclusion

Presentation quality matters. Speakers should be clear, audible, confident, well organised, and appropriately paced.
